# Manuscript data availability statement

Publication status: not yet formally published; manuscript dated 16 October 2026.

Repository: https://github.com/NickYWng/jasa-drone-musical-tones-data

> The numerical data supporting Figures 5–16 and Tables I–VI of this study are openly available in the accompanying GitHub repository at https://github.com/NickYWng/jasa-drone-musical-tones-data. The repository contains A-weighted spectrogram matrices, psychoacoustic time histories and summary statistics, annoyance-model correlation matrices, tabulated sound-pressure levels, and documentation of data provenance and processing. Figures 1–4 and the original pressure-waveform recordings are not included in this release.

The table time-window discrepancy is documented in `VALIDATION.md`; the repository preserves the submitted values without changing the manuscript.
